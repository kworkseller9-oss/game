# Mafia Online

Браузерная Мафия для игры с друзьями. React (Vite) + API на Vercel Functions + Postgres (Neon).
Регистрации нет: аккаунты создаёшь только ты в админ-панели.

## Деплой (всё бесплатно)

### 1. База данных (Neon)
1. Зайди на https://neon.tech и создай проект (Free).
2. Скопируй Connection string (вида `postgresql://...neon.tech/neondb?sslmode=require`).
Таблицы создаются сами при первом запросе, ничего вручную выполнять не нужно.

### 2. Код на GitHub
Распакуй zip, создай репозиторий и запушь проект.

### 3. Vercel
1. https://vercel.com -> Add New -> Project -> выбери репозиторий.
2. Framework: Vite (определится сам). Build: `npm run build`, Output: `dist`.
3. В Settings -> Environment Variables добавь:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка из Neon |
| `JWT_SECRET` | длинная случайная строка (32+ символа) |
| `ADMIN_LOGIN` | твой логин админа |
| `ADMIN_PASSWORD` | твой пароль админа |
| `MIN_PLAYERS` | `4` (для теста можно `1`) |

4. Deploy. Открой сайт и войди под `ADMIN_LOGIN` / `ADMIN_PASSWORD`.

### 4. Друзья
Вкладка «Админ» -> «+ Создать аккаунт» -> логин и пароль, передай другу.
Админ один: роль admin получает только пользователь из `ADMIN_LOGIN`,
через панель создаются только обычные игроки. Смена `ADMIN_PASSWORD` + redeploy обновит твой пароль.

## PWA
Приложение устанавливается на телефон и ПК (кнопка «Установить приложение» на входе и в меню).
- Android/Chrome и ПК: системное окно установки.
- iPhone: Safari -> «Поделиться» -> «На экран Домой».
- Офлайн кэшируется только оболочка сайта; сама игра требует интернет.
- После крупных обновлений поменяй `VERSION` в `public/sw.js`, чтобы у всех обновился кэш.
- PWA работает только по HTTPS, на Vercel это включено по умолчанию.

## Локальный запуск
```
npm install
cp .env.example .env     # заполни значения
npx vercel dev           # поднимает и фронт, и /api
```

## Как устроена игра
- Реалtime сделан через опрос (раз в 1,5 сек), потому что Vercel не держит WebSocket.
  Для компании друзей этого достаточно.
- Роли: мафия (1 на 3 игроков), доктор (от 5 игроков), шериф (от 6), остальные мирные.
- Ночь: мафия выбирает жертву (общий чат мафии), доктор лечит, шериф проверяет.
  День: обсуждение и голосование, больше всего голосов = изгнан. Ничья = никто.
- Режимы: Классика (ночь 45с, день 120с), Блиц (20с / 45с).
- Фаза переключается, когда все сходили или вышло время.

## Структура
- `api/index.js` — маршруты (вход, комнаты, игра, админка)
- `api/_lib/game.js` — правила игры
- `api/_lib/db.js` — схема БД и подключение Neon
- `src/` — интерфейс (вход, лобби, комната, игра, профиль, админ)
